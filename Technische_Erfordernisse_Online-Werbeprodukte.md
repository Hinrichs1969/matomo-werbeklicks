#### Technische Vorgaben Bilder (aus Live-Darstellung heide-kurier.de)

**Bilder**

| Element | Größe |
|---|---|
| **Titelbild / Cover** | **910 × 339 px** |
| **Bild im Text** | **880 × 660 px** |
| **Dateiformat** | JPG oder PNG · max. **2 MB** je Bild |
| **Anzahl Bilder** | **1 Titelbild** + **2–5** Bilder im Text |
| **Farbmodus** | sRGB (kein CMYK-Druck-PDF) |
| **Seitenverhältnis** | Titelbild ca. **2,7:1** (breit) · Textbild **4:3** |

**Text & Briefing**

| Element | Empfehlung |
|---|---|
| **Überschrift** | max. **70 Zeichen** (inkl. Leerzeichen) |
| **Teaser / Unterzeile** | max. **160 Zeichen** |
| **Fließtext** | **400–800 Wörter** (ca. 2.500–5.000 Zeichen) – oder Stichpunkte, wir formulieren |
| **Call-to-Action** | 1 klarer CTA-Satz + **1–3 Links** (Website, Formular, Telefon) |
| **Kontaktdaten** | Firma, Ansprechpartner, Telefon, E-Mail, Adresse |
| **Kernbotschaft** | **3–5 Stichpunkte**, was der Leser mitnehmen soll |

**Was der Kunde mindestens liefern muss**

1. Thema / Ziel der Story  
2. 3–6 Bilder  
3. Kontaktdaten + Ziel-URL(s)  
4. Stichpunkte oder Rohtext  

**Tipp Verkäufer:** *„Sie müssen keinen fertigen Artikel schreiben – Fotos und ein paar Stichpunkte reichen. Wir setzen den Text und das Layout."*

```
KUNDE WILL …                          → EMPFEHLUNG
─────────────────────────────────────────────────────────────
Maximale Aufmerksamkeit, großes Motiv  → Interstitial (E-Paper)
Kurze Aktion / Event / Sale            → E-Paper-Banner ODER Premiumbanner (HK-Online)
Prospekt / viele Seiten / Katalog      → Digitale Beilage (E-Paper)
Schon Print-Inserat, will Klicks       → Klickbare Anzeige (+29 €)
```
